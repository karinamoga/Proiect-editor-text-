# Text Editor - Instrucțiuni

## Cum să lucrezi

1. **NU schimba denumirea fișierelor** (obligatoriu pentru a rula checkerul):

2. **Implementează funcțiile** în `text_editor.c` și definește structurile în `text_editor.h`

3. **Rulează checkerul**:
   ```bash
   python3 checker_students.py
   ``` python3 checker.py

Checkerul va compila automat implementarea și va rula toate testele.

## Punctaj

- Testare funcționalitate: 65 puncte
- Testare performanță: 35 puncte
- **Total: 100 puncte**

Pentru a primi punctaj, implementarea ta trebuie să aibă complexitate eficientă pentru operațiile de inserare, ștergere și navigare.
